# skyisle-trader

浮遊島を飛行船で巡り、安く買って高く売る一人用の交易ゲーム。ターミナルで遊ぶ。

- 100 日で、どれだけ所持金を増やせるか(スコア = 終了時の所持金 − 1,000,000G)
- **島は毎日漂流する**: 島同士の距離、つまり移動日数が変わり続ける
- **自分の売買で相場が動く**: 買うほど値上がりし、売るほど値下がりする。時間がたつと戻る

```
┌ 空域 ─────────────────────────────┐ Day 1/100  残り 99 日
│                               ◆鐘 │ 所持金 867,978G  スコア -132,022
│                 ◇···              │ 現在地 星見島  積荷 80/200
│                   ◆翠··           │
│                        ····       │ ── 相場 星見島 ─────────────
│    ◆白               ◆霧     ·●星 │ > 魔石     7,310   6,579 名産   20
└─ ●現在地 ◆売り先 ◇合流点 ▲船 ─────┘ ↑↓選択 [b]買う [s]売る [t]出航
```

## 遊び方

Go 1.27 以上と、100 × 24 以上の端末が必要。

```sh
go install github.com/kikuchi-null/skyisle-trader@latest
skyisle-trader            # 毎回違うマップ
skyisle-trader -seed 42   # 同じ条件で遊び直す
```

島ごとに、品目の属性(**名産**は安い、**需要**は高い)が決まっている。名産の島で買い、需要の島で売るのが基本。属性は全島ぶん見えるが、現在の価格は今いる島のものしか見えない。

| キー | 動作 |
|---|---|
| `↑↓` | 品目を選ぶ |
| `b` / `s` | 買う / 売る(数字キーで個数を入力、`m` で最大、`Tab` で買う・売るを切り替え、`Enter` で確定) |
| `t` | 出航先を選ぶ(移動日数と、積荷を売ったときの目安の損益が見える) |
| `w` | 1 日待つ |
| `u` | 積載量を拡張する |
| `q` | 終了する |
